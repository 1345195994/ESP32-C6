# ESP32-C6-LED1.47
请使用本包 LVGL_Arduino 文件夹里的完整代码编译

本项目基于 ESP32-C6 主控 + 1.47寸高清显示屏 开发，是一款网页端可自定义的多功能智能桌面终端。
 
设备搭载 Wi-Fi 联网功能，支持网页后台可视化配置，无需修改代码即可实时修改设备内容除需要修改wifi名字和密码
 ，整体分为四大显示页面，自动切换、独立可控：

 

1. 首页综合信息页
自动联网获取实时天气、年月日、星期时间，同时显示当前校园路由器IP地址与网络状态。
​

2. 课程表展示页
支持网页自定义文本导入课表，可随时更新上课安排，适配学生日常学习使用。
​

3. 自定义文字页面
用户可在网页端自由输入任意文字、标语、备忘录，实现个性化屏幕展示。
​

4. 路由网络信息页
实时显示路由器详细网络参数、联网状态，方便查看校园网络连接情况。
